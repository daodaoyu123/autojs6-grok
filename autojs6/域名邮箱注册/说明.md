# 域名邮箱注册（主力流程）

AutoJs6 用 WebView 注册 x.ai / Grok。验证码发到**你的域名**（如 `*.445908.xyz`），
经 **Forward Email** 转发到 **QQ 邮箱垃圾箱**，Termux 里的「收验证码守望」取码写给注册脚本。

## 文件

- `域名邮箱注册.js`：AutoJs6 注册脚本。生成邮箱、填表、等验证码、完成注册并走 OAuth。
- `收验证码守望.py`：Termux 里运行的守望。读 `log/otp_want.txt`，刷 QQ 垃圾箱，写验证码文件。
- `说明.md`：本文件。

日志与验证码写在 `log/`：

- `otp_want.txt`：当前要收的邮箱，格式「地址|runid」
- `watch_run.txt`：守望日志
- `grok_otp_<runid>.txt`：取出的验证码，例如 `346-348`
- `grok_signup_webview.log`：注册脚本日志

账号和 sso 写在工作区 `grok/`（`grok_accounts.txt`、`sso_from_autojs.txt`），不写在本目录。

## 怎么跑

1. Termux 启动守望 + OAuth 服务（一条命令，幂等）：

```bash
bash ~/bin/start-watch.sh
```

2. AutoJs6 打开并运行 `域名邮箱注册.js`。

3. 状态在注册页顶部原生状态条，不跟网页跳转消失。阶段：
   等待接收验证码 → 提取验证码 → 提取成功 → 写入验证码。

## 配置（部署到新设备时要改两处）

- **守望的 QQ 邮箱**：设置环境变量 `OTP_QQ_USER`，或写一行到
  `~/.config/himalaya/qq.user`；授权码放 `~/.config/himalaya/qq.secret`（都是 600 权限）。
- **域名后缀**：改脚本顶部 `pickEmail()` 里的域名（默认 `445908.xyz`），
  同时在 Forward Email 配好 `*@*.你的域名 → QQ 邮箱` 的转发规则。

## 冻结
