# 04 · 常见问题（FAQ）

部署和踩坑相关的问题先看这里；教程正文分别在 01 / 02 / 03 三篇里。

---

## 部署相关

**Q: 账号导入成功，但 `synced=0, syncFailed=N` 全是同步失败？**
源码编译时显式指定了 `GOOS=linux CGO_ENABLED=0`。Android 没有 `/etc/resolv.conf`，
纯 Go 解析器回退 `[::1]:53` → 所有出站 DNS 全挂。用 Termux 默认目标重编：

```bash
cd ~/repos/grok2api/backend && go build -buildvcs=false -trimpath -ldflags="-s -w" -o ../grok2api ./cmd/grok2api
```

**Q: 前端 `pnpm install` 失败，报 @pnpm/exe android 包不存在？**
系统 pnpm 版本太高，会触发「版本自动切换」去找不存在的 android 原生包。用：

```bash
npm i -g --prefix ~/.pnpm11 pnpm@11.5.2
~/.pnpm11/bin/pnpm install --frozen-lockfile --fetch-timeout 300000 --fetch-retries 6
```

**Q: 出图/视频报 `link ... permission denied` 或 `media post-processing storage failed`？**
Android SELinux 禁止应用创建硬链接，grok2api 媒体存储提交用 `os.Link` 会失败
（但上游其实已生成成功）。本项目补丁把提交退化为「预检查 + rename」。确认补丁在：

```bash
grep commitNoReplace ~/repos/grok2api/backend/internal/infra/media/local_store.go
```

预编译包已含补丁；源码模式没打上看 `git apply` / `patch` 那段日志。

**Q: 手机重启后网关没起？**
`~/.bashrc` 钩子只在打开 Termux 时生效；要开机即起装 **Termux:Boot**（F-Droid），
`install-runtime.sh` 已写好 `~/.termux/boot/00-grok-router.sh`。

**Q: 怎么换端口？**
`bash deploy/gen-config.sh --port 9000 --force` 后重启；或手动改 `config.yaml` 的
`server.listen`。工具脚本认 `G2A_BASE` 环境变量（`export G2A_BASE=http://127.0.0.1:9000`）。

## 使用相关

**Q: 管理台登录一直 429？**
固定 1 分钟窗口限速（IP 30/分、同用户名 12/分）。等一分钟再登，别连点。
密码在 `~/grok2api_admin.txt`。

**Q: 管理台/网关在别的设备上打不开？**
默认只监听 `127.0.0.1`（安全设计）。要在局域网用，改 `config.yaml` 的
`server.listen: "0.0.0.0:8000"` 并自己控制访问（加防火墙/仅信任网络），再重启。

**Q: 手机换 Wi-Fi 后 CLI/客户端连不上了？**
本机链路（127.0.0.1）不受影响；受影响的是你若有局域网直连。IP 变了改客户端地址即可。

**Q: 服务正常但用户说「断开」？**
逐层查：`ps` 进程五件套（grok2api / grok-cli-shim / grok-8800-alias / grok_oauth）→
`curl /healthz`（8000/8802/8800）→ `g2a_smoke.py` 真实对话 → 看日志时间戳是不是旧账。
全绿还报错就问清「哪个界面、哪行原文」。

**Q: 出图的 URL 打不开？**
媒体走网关本地存储（`data/media`），要用带 key 的本机地址访问；
或从管理台媒体页下载。

**Q: 视频 480p / 更长时长？**
免费号 720p 是实测上限（480p 反而要 Super）；时长被网关截。要更高能力需要会员级账号。

**Q: Console 池的号额度是多少？**
chat 每号 10 条/天；媒体窗口 0/0 是余额未发放免费额度（不是故障），视频走 Web 池。

**Q: 某个账号突然 401 / credentials rejected？**
refresh token 轮换机制：池子刷新后旧副本失效。典型原因是**同一个号被两套系统同时刷**——
要么分号（各拿一半），要么让旧系统退出这批号。给客户端重新登录换新 token 即可恢复。

## 注册相关

**Q: 注册完了，为什么池子数量没变？**
注册只写文件，不会自动入池。跑导入工具（`g2a_import_new.py` / `g2a_web_test.py` /
`g2a_sync_console.py`），用管理台账号数核对。

**Q: 域名邮箱流程收不到验证码？**
按顺序查：QQ 授权码（`~/.config/himalaya/qq.secret`）→ 邮箱地址
（`~/.config/himalaya/qq.user` 或 `OTP_QQ_USER`）→ Forward Email 转发规则 →
守望进程在不在（`bash ~/bin/start-watch.sh`，日志 `域名邮箱注册/log/watch_run.txt`）。
注意守望**只看 QQ 垃圾箱 Junk**，不看收件箱。

**Q: 注册被 x.ai 拒绝（邮箱 disposable）？**
脚本内置子域轮换会自动换域名重试；还不行换 VPN 节点（出口 IP 风控）。

**Q: Outlook 链报「被阻止」？**
IP 被微软标记了：批量脚本会立刻停止 —— 换 VPN 节点（快橙切线路）后重跑。

**Q: AutoJs6 下发脚本没反应（Termux 连不上 7347）？**
打开 AutoJs6 侧边抽屉 →「服务端模式」；熄屏会冻结进程 → 权限里放开后台 + 亮屏跑。
桥工具默认连 `127.0.0.1`，跨设备用 `AUTOJS_HOST=<局域网IP>`。

**Q: 快橙 VPN 影响吗？**
注册 x.ai 需要非受限出口，快橙常开没问题（机房 IP 有时也会被风控，换节点）。
注意：grok2api 的 Egress 功能**不直接支持 OpenVPN（.ovpn）**，快橙这类节点不能直接加进网关的
Egress 池；要在独立 Linux 机上转成 SOCKS/HTTP 等协议才行。

**Q: 收验证码守望能不能挂后台常驻？**
可以，本来设计就是常驻（空闲不退出）；重启脚本会自动换目标邮箱。
停掉：`tmux kill-session -t watch_otp`。

## 安全相关（重要）

- 所有服务默认只监听 `127.0.0.1`，不要图方便改成 `0.0.0.0` 还不加认证 ——
  等于把你的高权限多账号池变成公开代理
- `~/grok2api_admin.txt`、`~/grok2api_keys.txt`、`~/.config/himalaya/qq.secret`、
  `xai-*.json`、`sso_from_autojs.txt` 都不要外传、不要进 Git
- 仓库里 `config.yaml` 是**生成物**：源码仓库只放模板（`config.termux.yaml`），
  真实密钥永远只在设备上
