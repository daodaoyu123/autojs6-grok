# 03 · 使用教程

网关跑起来后，这里讲怎么用：管理台、导入账号、调 API、接 Hermes / grok CLI、玩媒体能力。

---

## 1. 管理台

浏览器打开 `http://127.0.0.1:8000`，用 `~/grok2api_admin.txt` 里的账号密码登录。

能做的事：

- **账号池管理**：查看/启停各池账号、同步状态、用量与额度窗口
- **客户端 Key**：管理调用密钥（前缀 + 备注，secret 只在创建时显示一次）
- **请求审计**：每个请求用了哪个号/模型/出口节点/状态码
- **媒体资产**：图片/视频文件与元数据
- **系统设置**：媒体容量清理策略、Quality Guard 开关等

登录限速提示：`/auth/login` 是固定 1 分钟窗口限流（同 IP 30/分、同用户名 12/分），
反复刷新输错会 429，等一分钟即可，别连点。

## 2. 导入账号（三个池）

| 池 | 凭证形态 | 能力 | 导入工具 |
|----|----------|------|----------|
| **Build** | OAuth refresh token（`xai-*.json`） | 文本对话、Agent 工具调用 | `g2a_import_new.py` |
| **Web** | SSO cookie | 图像生成、视频（720p） | `g2a_web_test.py` |
| **Console** | 由 Web SSO 同步而来 | 视频、语音、Realtime、更多模型 | `g2a_sync_console.py` |

```bash
# Build 池：把最近 60 分钟新产出的 token 文件导入
python3 ~/bin/g2a_import_new.py --since 60
# 也可以点名导入：python3 ~/bin/g2a_import_new.py 邮箱1 邮箱2

# Web 池：导入 sso 列表 + 自动跑预处理（同意条款/生日/NSFW），并试一次出图
python3 ~/bin/g2a_web_test.py

# Console 池：把还没 Console 的 Web 号同步过去（87/87 实测）
python3 ~/bin/g2a_sync_console.py count      # 看三池数量
python3 ~/bin/g2a_sync_console.py missing    # 只同步缺的（推荐）
```

**注册成功 ≠ 已入池**：AutoJS6 注册只写文件；必须跑上面的导入命令，用管理台的
账号总数核对，别拿文件行数当入池数。

## 3. 创建客户端 Key

```bash
python3 ~/bin/g2a_admin.py key my-app    # 创建名为 my-app 的 Key，secret 落盘 ~/grok2api_keys.txt
cat ~/grok2api_keys.txt                  # 名称 / 前缀 / secret（600 权限，勿外传）
```

secret 形如 `g2a_...`，只在创建时完整显示一次；`~/grok2api_keys.txt` 里存了副本。
**任何情况下不要把 key 贴到聊天/截图/代码仓库里。**

## 4. 调用 API（OpenAI 兼容）

把 `base_url` 指到本机网关、`api_key` 用 g2a_ key 即可，官方 OpenAI SDK 直接可用：

```python
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="g2a_你的密钥")

r = client.chat.completions.create(
    model="grok-4.5",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)
print(r.choices[0].message.content)
```

curl 版：

```bash
curl -s http://127.0.0.1:8000/v1/chat/completions \
  -H "Authorization: Bearer g2a_你的密钥" -H "Content-Type: application/json" \
  -d '{"model":"grok-4.5","messages":[{"role":"user","content":"你好"}]}'
```

要点：

- **模型名**：以 `GET /v1/models` 实际返回为准（grok-4.5 / grok-4.6 / grok-4.7 /
  grok-composer-2.5-fast / grok-chat-fast / 图像 / 视频 / voice 等）
- **指定池**：裸 `grok-4.5` 默认走 Console 池；要指定用前缀 `Build/grok-4.5`、
  `Console/grok-4.5`、`Web/...`（大量测试优先 `Build/`，省 Console 的每日 10 条/号额度）
- **流式**：`"stream": true` 真 SSE 透传；带 `stream_options: {"include_usage": true}` 可拿用量
- **工具调用**：`tools` / `tool_choice` 全透传，可直接做 Agent
- **Anthropic 协议**：网关同时兼容，`/v1/messages` 可接 Claude 系客户端

## 5. 接入 Hermes Agent

```bash
hermes config set custom_providers \
  '[{"name":"grok-pool","base_url":"http://127.0.0.1:8000/v1","api_key":"g2a_你的密钥","models":["grok-4.5"]}]' --force
hermes config set model_aliases.grokpool '{"model":"grok-4.5","provider":"custom:grok-pool"}' --force
hermes config set model.default grokpool --force

# 验证
hermes chat -Q -m grokpool -q '只回复：路由测试成功'
```

坑：裸 `-m grok-4.5` 会落到默认 provider，必须用别名（`grokpool`）或
`custom:grok-pool` 语法；验证铁证看 `~/.hermes/logs/agent.log` 里是否
`provider=custom` + `base_url=127.0.0.1:8000`。

## 6. 接入 grok CLI

grok CLI 坚持发「会话 token」，而 grok2api 只认 g2a_ key，所以要垫一层转换层（shim）：

```bash
~/bin/grok-shim-up.sh          # 起 127.0.0.1:8802 转换层（幂等）
```

`~/.grok/config.toml` 里加模型条目：

```toml
[model.grokpool]
base_url = "http://127.0.0.1:8802/v1"
api_key = "占位即可（shim 会替换）"
model = "grok-4.5"
```

旧地址 `http://127.0.0.1:8800/v1` 也保留：转发到 8000 + 浏览器打开自动登录管理台。

## 7. 媒体能力

### 图像（Web 池）

```bash
curl -s http://127.0.0.1:8000/v1/images/generations \
  -H "Authorization: Bearer g2a_你的密钥" -H "Content-Type: application/json" \
  -d '{"model":"grok-imagine-image","prompt":"一只穿宇航服的橘猫"}'
```

返回 `//v1/media/images/...` URL，直接在浏览器打开即可。`grok-imagine-image-edit`
走图生图（输入图必须是可公网下载的 HTTPS URL）。

### 视频（Web 池，720p）

```bash
python3 ~/bin/g2a_video_test2.py    # 实测：6s / 5.6MB MP4（模型 grok-imagine-video + resolution:720p）
```

创建响应用 `request_id`（snake_case）轮询；要竖屏/横屏在请求里带 `aspect_ratio`。

### 语音（Console 池）

```bash
# TTS → 真 MP3
curl -s http://127.0.0.1:8000/v1/audio/speech \
  -H "Authorization: Bearer g2a_你的密钥" -H "Content-Type: application/json" \
  -d '{"model":"grok-voice-latest","input":"你好，这是一段测试","voice":"eve"}' -o out.mp3

# STT：multipart 传 file + model=grok-stt
python3 ~/bin/g2a_voice_test.py
```

## 8. 日常运维

```bash
# 一键冒烟（模型列表 + 真实对话）
python3 ~/bin/g2a_smoke.py

# 全模型真跑一遍（10 个模型逐发真实请求，输出 PASS/FAIL 表）
python3 ~/bin/g2a_models_test.py

# Agent 能力三回合闭环测试
python3 ~/bin/g2a_agent_test.py

# 日志
tail -f ~/repos/grok2api/grok2api.log
tail -f ~/.grok/logs/shim.log

# 健康
curl -s http://127.0.0.1:8000/healthz
```

- **额度是滚动 24 小时**：每个号按自己上次消耗起算 24h 重置，各号时间错开；
  管理台「额度」列是滚动窗口的实测用量，不是整点重置
- **批量启停账号**：管理台里多选操作；或 `PATCH /api/admin/v1/accounts/batch {provider, ids, enabled}`
- **质量守护**：`qualityGuard.enabled` 打开后自动探测/隔离异常账号（默认关）
- **共号警告**：同一个号不要同时被两套系统刷新（refresh token 会轮换互踢）；
  已迁移的系统就别再让旧路由碰这批号

## 9. 常见调用故障

| 症状 | 处理 |
|------|------|
| 401 `invalid_api_key` | key 错了或用了上游 token；用 `~/grok2api_keys.txt` 里的 g2a_ key |
| 503「当前没有可用的上游账号」 | 池里没号/全被限流；看管理台，导入或换个模型 |
| 429 | 号池额度用尽或上游限流；换模型/等滚动窗口 |
| 流式 200 但内容是错误帧 | 解 SSE 看 `"error"` 字段（有些错误被 200 包着） |
| 出图 500 提到 `link ... permission denied` | 硬链接补丁没打，重装（见 01 部署教程） |
